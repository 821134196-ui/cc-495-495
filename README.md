# 实习三方协议平台

学校用于登记学生实习单位、岗位、指导老师、实习周期与三方协议版本的演示系统。
流程:学生提交岗位信息 → 学院核对培养要求 → 单位联系人确认职责 → 三方电子签署;
已生效协议的任何变更都会生成新版本,需受影响方重新确认,旧版本同时失效。

## 启动(一条命令)

```bash
python3 run.py            # 建库 + 种子数据(含撤岗样例)+ 启动服务
# 访问 http://127.0.0.1:5000
python3 run.py --reset    # 清空数据重新种子
```

依赖:Python 3.11+ 与 Flask(已安装)。首次启动自动生成 `data/` 下的
SQLite 库、协议文件、附件与模拟适配器日志。

## 测试

```bash
python3 -m pytest tests/ -q
```

覆盖:签署顺序强制、旧版本不可重新生效、跨学院隔离、两名审核人并发确认
(旧版本只失效一次)、学生不能代单位确认、变更前后实习天数连续可查、
撤岗/联系人更换/附件修订的版本链、种子撤岗样例。

## 功能地图

| 页面 | 说明 |
| --- | --- |
| 签署进度 `/` | 按学生、学院、单位三方展示每条申请的签署/确认状态 |
| 岗位申请 `/apply` | 学生选岗位、指导老师(限本学院)、实习周期 |
| 申请详情 `/applications/<id>` | 审核、单位确认、签署、发起变更、版本链、天数台账、操作留痕 |
| 变更对比 `/applications/<id>/compare` | 任意两版并排对比,岗位/日期等差异高亮 |
| 指导老师待办 `/todo` | 本学院待审核、待签署、待确认变更三类待办 |
| 协议归档 `/archive` | 全部版本与附件(带版本号),协议全文独立页面阅读 |

右上角下拉切换身份(学生/指导老师/单位联系人),无需登录。

## 种子数据与撤岗样例

- **APP-1(撤岗样例)**:张晓在云舟科技的后端实习,第 1 版三方签齐生效;
  单位撤岗后生成第 2 版(转测试开发岗、结束日期提前),学生与学院重新确认后
  第 2 版生效、第 1 版失效。天数台账:07-01~09-16(第1版)+ 09-17~11-30(第2版),连续可查。
- **APP-2**:李华的申请签署流程进行中(学生已签,等学院签),可在待办中继续。
- **APP-3**:赵雪的申请待学院审核。

## 设计要点

- **版本链**:每次变更(撤岗/转岗/提前结束/联系人更换/附件修订)生成新版本,
  `prev_id` 串联;受影响方(三方中除发起方)逐一点确认,全部确认后原子切换。
- **并发安全**:状态切换全部使用 `BEGIN IMMEDIATE` 事务 + CAS 更新
  (`UPDATE ... WHERE status='...'` 检查影响行数),并有
  `one_effective_per_app` 部分唯一索引兜底——两名审核人同时操作时,
  旧版本只会失效一次,绝不被重新生效。
- **签署顺序**:学生 → 学院 → 单位;越序、越权、签署已失效版本都会被拒绝
  并写入 `audit_log`(详情页"操作留痕"可见)。
- **权限**:学生不能代单位确认;老师只能审核/签署本学院(本人指导)的申请;
  单位联系人只能操作本单位岗位。
- **天数台账**:`segments` 表分段记录,变更生效时旧段截止于前一日、
  新段当日接续,页面校验连续性并累计总天数。
- **模拟适配器**:`app/adapters.py` 中 `MockSignatureAdapter`(伪签名串 +
  `data/logs/signatures.log`)与 `MockNotificationAdapter`(通知表 +
  `data/logs/notifications.log`),接口与真实 CA/通知网关一致,可整体替换。
- **本地协议文件**:`data/agreements/APP-<id>-v<n>.txt` 为虚构协议正文,
  `data/attachments/APP-<id>-att-v<k>.txt` 为附件,版本号体现在文件名中。

## 目录结构

```
run.py               # 一条命令启动
app/
  db.py              # SQLite schema、事务助手
  services.py        # 业务逻辑(申请/审核/签署/变更/台账)
  adapters.py        # 模拟签名与通知适配器
  seed.py            # 种子数据(含撤岗样例)
  web.py             # Flask 路由
  templates/ static/ # 页面与样式(白 / 深灰 / 校园蓝)
tests/test_flows.py  # 流程与并发测试
data/                # 运行时生成:internship.db、agreements/、attachments/、logs/
```
